# Matériaux Cassis

Retire le panneau des matières et intègre les quatre choix à la carte Cassis, comme Escale.

Depuis la racine du site :
```sh
node releases/cassis-20261023/Installer-cassis.mjs --apply
```

Vérifie les fichiers, sauvegarde les deux sources et dist, compile avant remplacement. Refuse les modifications inattendues. Les images existantes sont réutilisées. Aucun redémarrage nécessaire.
